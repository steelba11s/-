# Простая карта

Учебное настольное приложение на C# и Avalonia. Карта OpenStreetMap через Mapsui, поиск адресов через Photon.

## Запуск

Из общей папки проектов:

```powershell
dotnet run --project .\SimpleMap\SimpleMap.csproj
```

Также можно открыть `SimpleMap.slnx` в IDE или дважды нажать `Start.cmd`.
Требуются .NET SDK 9 или 10 и среда выполнения .NET 9. При первом запуске загружаются зависимости NuGet.

## Возможности

- Перемещение карты: удерживать левую кнопку мыши и перетаскивать.
- Масштабирование: колесо мыши или кнопки «+» и «−».
- Поиск: ввести город, улицу и дом, нажать «Найти» или Enter.
- Выбрать один из результатов: карта перейдёт к адресу и выделит его точкой.

При запуске отображается Москва. Маршруты, пробки, геолокация, аккаунты и офлайн-карты не реализованы.

## Устройство

В решении один проект. `MainWindow.axaml` описывает окно, `MainWindow.axaml.cs` связывает карту и кнопки, `AddressSearch.cs` отправляет запрос поиска и читает ответ, `MapSettings.cs` загружает настройки.

`map-settings.json` содержит адреса картографического и поискового сервисов. Его копия рядом с приложением позволяет сменить провайдера без изменения кода; новый поисковый сервис должен поддерживать формат Photon.

Карта требует интернет. Уже просмотренные участки кешируются на 7 дней в `%LOCALAPPDATA%\ArturSimpleMap\tiles`. Это обычный кеш, а не скачанная карта города. Поиск выполняется только после действия пользователя, не чаще одного запроса в секунду; повторные запросы хранятся в памяти до закрытия программы. Ключи API и регистрация не нужны.

Адресный запрос отправляется Photon, запросы участков карты — серверу OpenStreetMap. Сервисы могут быть временно недоступны; полнота адресов зависит от данных OSM. Публичный Photon рассчитан на умеренное использование, не на массовые запросы.
