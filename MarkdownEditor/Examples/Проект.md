# Заметки к проекту

## Markdown-редактор

Локальные документы, рабочие заметки и идеи в одном месте.

### План работы

- [x] Определить тему проекта
- [x] Подготовить интерфейс
- [ ] Описать результаты
- [ ] Проверить результат

### Структура документа

| Раздел | Содержание |
| --- | --- |
| Введение | Цель и задачи |
| Реализация | Устройство приложения |
| Проверка | Результаты тестирования |

> Хорошая заметка сохраняет не только решение, но и причины его выбора.

### Пример кода

```csharp
string text = "# Моя заметка";
await File.WriteAllTextAsync("note.md", text);
```
