# Техническое задание

## Назначение

Локальное настольное приложение для редактирования и просмотра Markdown-файлов. Язык C#, интерфейс Avalonia.

## Требования

1. Слева отображается дерево выбранной папки и Markdown-файлов.
2. В центральной части располагается редактор исходного Markdown.
3. Справа располагается обновляемый предпросмотр.
4. Можно открывать и сохранять `.md` файлы.
5. Есть поиск по текущему документу и по выбранной папке.
6. Есть экспорт Markdown в HTML.
7. C# + Avalonia UI; раздельные представление и логика по MVVM; Markdig для обработки Markdown.
8. Без переключения светлой и тёмной темы.

## Критерии приёмки

- Открытый файл виден в редакторе; кириллица читается и сохраняется без искажений в поддерживаемых кодировках.
- После изменения Markdown предпросмотр обновляется, а документ отмечается как изменённый.
- Сохранённый файл можно открыть повторно с тем же содержимым.
- При несохранённых изменениях предлагается сохранить, продолжить без сохранения или отменить действие.
- Отмена диалога сохранения сохраняет открытый документ и его правки.
- Результаты поиска содержат файл, строку и фрагмент текста; выбор результата выделяет найденный текст.
- Экспортированный HTML открывается браузером и содержит форматированный документ.
- Интерфейс работоспособен при размере окна от 1000 × 640.

## Дополнения для удобства

Новый документ, «Сохранить как», команды форматирования, отмена и повтор, режимы отображения, горячие клавиши, счётчики, обработка ошибок доступа и проверка внешних изменений перед сохранением.

Технические ограничения и инструкции запуска приведены в README.md.
