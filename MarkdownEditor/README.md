# Markdown-редактор

Файзуллин Артур. Учебный проект на C# и Avalonia.

## Возможности

Открытие папки и Markdown-файлов, редактирование с предпросмотром, сохранение, поиск в документе или папке, экспорт в HTML. Есть отмена действий, кнопки форматирования и предупреждение о несохранённых изменениях.

## Запуск

Для сборки нужен .NET SDK 10. Откройте `MarkdownEditor.slnx` либо выполните из папки проекта:

```powershell
dotnet restore MarkdownEditor.slnx --configfile NuGet.Config
dotnet run --project MarkdownEditor.App
```

Дважды нажмите `Start.cmd`, чтобы собрать и запустить актуальные исходники через .NET SDK. После сборки можно открыть `MarkdownEditor.App\bin\Debug\net10.0\MarkdownEditor.exe` напрямую (нужна среда выполнения .NET 10).

## Структура

- `MarkdownEditor.App` — окна, разметка Avalonia, предпросмотр, состояние документа, команды, файлы, поиск и экспорт.
- `Examples` — пример Markdown-документа.

Обработка Markdown: Markdig. Значки интерфейса: Lucide.Avalonia. Требования перечислены в `SPEC.md`.

## Проверка и сборка

```powershell
dotnet build MarkdownEditor.slnx
dotnet publish MarkdownEditor.App -c Release -r win-x64 --self-contained true -o bin/Release/win-x64
```

Готовая программа: `bin/Release/win-x64/MarkdownEditor.exe`. Для переноса копируйте всю папку `win-x64`; установка .NET на целевом компьютере не требуется.

## Ограничения

Один открытый документ, размер до 4 МБ. Поддерживаются UTF-8 и UTF-16/UTF-32 с BOM. Поиск показывает до 500 совпадений, дерево — до 10 000 элементов и 30 уровней вложенности. Скрытые, системные каталоги, символические ссылки и каталоги сборки пропускаются.

Предпросмотр показывает локальные растровые изображения до 16 МБ; сетевые изображения открываются по ссылке в браузере. HTML-экспорт не включает файлы изображений: при переносе документа нужно перенести ресурсы и обновить пути. Встроенный HTML отображается как текст.

Проверка внешних изменений перед сохранением не заменяет блокировку файла при одновременной работе нескольких программ.
